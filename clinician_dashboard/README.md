# BioTective Clinician Dashboard

This Flutter application is a prototype for the Clinician Dashboard component of the BioTective AI-Enabled Digital Health Platform for Chronic Disease Monitoring.

## Overview

The Clinician Dashboard provides healthcare professionals with tools to monitor and manage patients with chronic conditions. The dashboard includes:

- Patient list with risk-level indicators
- Priority alerts panel
- Detailed patient health data visualizations
- AI-generated insights and recommendations
- Communication interface for patient interaction

## Features

### Patient Management
- View list of patients with risk indicators
- Search and filter patients by name, ID, risk level, and last update
- Access detailed patient information

### Clinical Monitoring
- View glucose trends and HbA1c readings
- Track physical activity patterns
- Review diet logs and meal entries
- Monitor automated system actions

### AI-Powered Insights
- AI-generated health summaries
- Detected patterns in patient data
- Personalized recommendations
- Automated actions log

### Communication
- Add clinical notes
- Send messages to patients
- Schedule follow-ups and appointments
- Request additional health data

## Getting Started

### Prerequisites
- Flutter SDK (version 3.0.0 or higher)
- Dart SDK (version 3.0.0 or higher)

### Installation
1. Clone the repository
2. Navigate to the project directory
3. Run `flutter pub get` to install dependencies
4. Run `flutter run` to launch the application

## Project Structure

- `/lib/models`: Data models for patients, health data, and clinical notes
- `/lib/screens`: Main application screens
- `/lib/widgets`: Reusable UI components
- `/lib/services`: Data services and API connections
- `/lib/theme`: Application styling
