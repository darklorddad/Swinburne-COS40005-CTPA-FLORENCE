AI-Enabled Digital Health Platform for Chronic Disease Monitoring

A Project for BioTective Sdn Bhd

biotech Introduction

This project, undertaken for BioTective Sdn Bhd, involves the prototype development of an AI-enabled digital health platform for chronic disease monitoring. In Malaysia, chronic, non-communicable diseases (NCDs) are the leading cause of death and disability, placing an immense strain on a healthcare system primarily designed for acute, episodic care [1]. Patients often struggle with fragmented health information and a lack of real-time monitoring. This project aims to create a prototype that integrates multi-source health data (e.g., glucose levels, diet, activity) and uses Artificial Intelligence to provide actionable insights. The platform is designed to facilitate timely interventions by both patients and clinicians, transforming chronic disease management from a reactive process into a proactive, data-driven partnership.

troubleshoot Problem

The core problem is that chronic disease patients lack a unified platform that integrates their fragmented health data and provides real-time, actionable, and personalised guidance.

  • Patient Pain Points: Fragmented records, difficulty with self-management, and the burden of long-term illness [3].
  • Clinician Pain Points: Systemic overload, lack of integrated data, and inefficiency of the acute care model [1].

plagiarism Literature Review

A competitive analysis reveals a market gap [2, 4]. Platforms like *DoctorOnCall* are reactive. *BookDoc* focuses on general wellness, while *Naluri Health* uses a human-coaching model that is difficult to scale. There is an unmet need for a scalable, automated platform that fosters a continuous, proactive care relationship, moving beyond the episodic interactions that dominate the market [4].

hub Methodology

The solution is a high-fidelity prototype built on a modern, decoupled system architecture using a microservices-style approach (Platform, Data, and LLM Chatbot services) for scalability and security.

Technology Stack:

  • Frontend: Flutter for high-performance, cross-platform UI.
  • Backend: Python & FastAPI for performance and AI/ML libraries.
  • Database: Supabase (PostgreSQL) with Row-Level Security.

AI Core:

Implemented as an autonomous agent using LangChain. The agent leverages LLM tool-calling capabilities, using custom Python functions to interact with the Data Service to fetch live patient data (e.g., glucose readings) to generate a personalised, context-aware response.

flag Conclusion

This project addresses a critical gap by prototyping an AI-powered platform for proactive chronic disease management. It empowers patients in self-management and provides clinicians with an intelligent "attention funnel" to prioritise high-risk individuals, improving efficiency and enabling timely interventions.
