# FLORENCE Admin Portal - User Manual

## 1. Introduction
The FLORENCE Admin Portal is the operational backbone of the ecosystem. It is designed to keep everything running smoothly by handling user management, organizational structure, and platform analytics.

## 2. Dashboard Overview
Upon logging into the Admin Portal, you are presented with a high-level view of platform activity. The dashboard provides quick access to the four core administrative functions:
- User Management
- Platform Metrics
- Patient Directory
- Assign Clinicians

## 3. Core Administrative Functions
### 3.1 User Management
This module allows administrators to control access to the platform.
- **Add Users**: Register new patients or clinicians onto the platform.
- **Manage Roles**: Update user permissions and roles.
- **Remove Users**: Deactivate or remove accounts that are no longer active to maintain security.

### 3.2 Platform Metrics
Monitor the overall health and adoption of the FLORENCE platform.
- View live statistics on daily active users (patients and clinicians).
- Track the volume of data being logged (e.g., number of meals scanned, vitals recorded).
- Monitor system performance and alert volumes.

### 3.3 Patient Directory
A comprehensive, searchable database of all patients registered on the platform.
- Use the search bar to find specific patients by name or ID.
- Filter patients by condition, assigned clinic, or onboarding status.
- View basic demographic and assignment information (clinical data remains secure and restricted to the clinician interface).

### 3.4 Assign Clinicians
Link patients to their managing healthcare providers.
- Select a patient from the directory.
- Assign them to a specific clinician or a clinical team.
- This ensures that the patient's data flows directly into the correct clinician's Dynamic Risk Engine queue.
